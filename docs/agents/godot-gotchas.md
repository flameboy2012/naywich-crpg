# Godot 4.7 .NET gotchas

Lessons verified on this machine during M1. They cover what the config files and code don't tell you. For the project layout, read the repo itself.

Engine: `E:\files\godot\Godot_v4.7.2-stable_mono_win64_console.exe` (not on PATH). Use the `_console` exe so you get stdout.

## The verify loop

Run these in order from `game/`, every time:

1. `dotnet build ..\Crpg.sln`. Godot cannot find C# classes until they are built ("associated class could not be found"). Prefer this to `--build-solutions`, because it shows real compiler errors.
2. `--headless --path . --import`. Always run this in a fresh clone or worktree, and after adding PNGs or `.cs` files. `dotnet build` creates `.godot/` without importing assets. New `.cs.uid` files only appear on import; commit them.
3. `--headless --path . --fixed-fps 60 --quit-after N`. With `--fixed-fps 60`, N frames is N/60 seconds of game time, so results are repeatable.
4. Grep the output for `ERROR:`. Godot exits 0 even when scripts throw, so the exit code proves nothing. Only the check tools' own `Quit(1)` gives a non-zero exit.

Give every `--script` run a `--quit-after`. A tool that throws before `Quit()` hangs forever.

## Headless checks

Engine-level checks live in `game/tools/*Check.cs` and share `HeadlessCheck.cs`. They push real mouse input through the viewport and fail with a non-zero exit. Run each one with `--script res://tools/<Name>.cs` and a generous `--quit-after` (the doc comment in each file gives the command). Keep all of them passing, and add one for each new engine behaviour.

The zone and art are generated by `game/tools/BuildTestZone.cs` and `GenArt.cs`. Change those tools and rerun them; don't hand-edit the generated `.tscn`, `.tres` or PNGs. A rerun changes random `unique_id` values in `TestZone.tscn`. Revert those if nothing else changed.

## Navigation

- **Map sync lag.** For several frames after a zone loads, `NavigationServer2D.MapGetClosestPoint` and `MapGetPath` return (0,0) or empty, even once `MapGetIterationId > 0`. A check that asserts "closest point differs from the input" then passes without testing anything. Wait until a known ground point maps to itself before asserting.
- **Baking needs outlines.** Tile navigation polygons need `outlines`, not just `polygons`, or the `NavigationRegion2D` bake gives 0 polygons.
- **Layout.** The zone is `NavigationRegion2D > TileMapLayer`, with `NavigationEnabled = false` on the layer. Obstacle tiles carve holes through their collision polygons.
- **Agent distances.** The `NavigationAgent2D` default distances stop well short of the target. The project uses 4 px.

## Physics and input

- A point query on an obstacle tile hits the TileMapLayer, which is a static body. Clicks therefore query only the characters' click areas, which have their own physics layer. Check the layer constants in the code before adding new clickable things.
- Godot's `MouseButton` clashes with any Core type of the same name. Use an alias if needed.

## Files and git

- **No BOM.** A `.tscn` with a UTF-8 BOM fails to parse (`Expected '['`). PowerShell 5.1 `Set-Content`/`Out-File -Encoding utf8` and `dotnet new sln` all write a BOM. Use the Write tool, or `[IO.File]::WriteAllText(path, text, (New-Object Text.UTF8Encoding $false))`.
- **The editor rewrites `project.godot`.** The first time the project opens in the editor, Godot rewrites the file's header. Commit that before switching branches, or the checkout fails.
- **SDK 10 defaults.** `dotnet new sln` makes `.slnx` unless you pass `--format sln`. `dotnet new` rejects `-f net8.0`, so set `<TargetFramework>net8.0</TargetFramework>` by hand. Every project targets net8.0.
- **Old git (2.15).** Agent worktree isolation fails (`unknown option 'no-track'`). `git worktree remove`, `git branch --show-current` and `git add --renormalize` don't exist. Create worktrees with `git worktree add -b <branch> <path> <base>`, and clean up by deleting the folder and running `git worktree prune`. In a worktree, pass absolute paths to .NET file APIs, because relative paths can resolve against the main checkout.
